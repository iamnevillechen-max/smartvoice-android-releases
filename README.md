# SmartVoice 中文版

Android 系統 TTS 引擎，含原有 45 個音色。中文介面分為音色、語言分配及設定，支援全局語速倍數、音色包下載、線上及本地 APK 更新。

[下載 0.1.1-beta.3 完整安裝包](https://github.com/iamnevillechen-max/smartvoice-android-releases/releases/download/v0.1.1-beta.3/SmartVoice-0.1.1-beta.3-release.apk)

最低 Android 8，ARM64；目標 Android 17。Android 15／17 的 ARM64 模擬器系統 TTS 長短句已測通。紅米實機、使用者聆聽及 TalkBack、16 KB 系統頁實際運行尚未驗收。

`update.json` 和 `voices.json` 為 App 的穩定更新目錄；APK 與語音資料在固定版本的 Release assets。此庫只發行產物，不存放簽署私鑰。
