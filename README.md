# SceneVox TTS

[查看最新正式版](https://github.com/iamnevillechen-max/smartvoice-android-releases/releases/latest) · [直接下载 2.4.1 安卓安装包（ARM64）](https://github.com/iamnevillechen-max/smartvoice-android-releases/releases/download/scenevox-v2.4.1/SceneVox-TTS-2.4.1-arm64.apk)

手机上打开 SceneVox，在「用户 → 检查更新」可下载并安装新版。

Android 系统文字转语音引擎，支持多引擎音色、按语言朗读、多角色对话、场景音效和本地声音克隆。

默认旁白为中文婷婷、英文 Samantha。在「人物」按姓名指定音色，或在右上角「更多」开启自动匹配。

「声音」可试听、调整和导入音色。「配音」可搜索、试听场景音效，在「更多」开启自动匹配，或选择下载离线包。

沿用 com.scenevox.tts，可覆盖安装并保留已有音库和设置。

An Android text-to-speech engine with offline and online voices, character dialogue, scene sounds and local voice cloning. Open User → Check for updates to update the app.
