# SceneVox TTS

当前版本：**2.2.5** · [下载 APK](https://github.com/iamnevillechen-max/smartvoice-android-releases/releases/download/scenevox-v2.2.5/SceneVox-TTS-2.2.5-arm64.apk)

Android 系统文字转语音引擎，支持多引擎音色、按语言朗读、多角色对话、场景音效和本地声音克隆。

默认旁白为中文婷婷、英文 Samantha；对话方案由用户新建或导入。

声音、对话、场景、用户四个页面。声音和音效包可先试听再下载；每个声音只有一个读屏焦点。点开声音即可试听，并调节语速、语调和音量。对话方案分别保存角色音色，场景音效随朗读出现并自然渐弱。

沿用 com.scenevox.tts，可覆盖安装并保留已有音库和设置。

An Android text-to-speech engine with offline and online voices, language-aware narration, character dialogue, scene sounds and local voice cloning. Preview resources before downloading and manage them in four pages: Voices, Dialogue, Scenes and User.
